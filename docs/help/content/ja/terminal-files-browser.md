エージェントペインの横に、ターミナルとファイルのペインを一緒に開いておけます。

## ターミナルペイン {#terminal}
ワークスペースのフォルダで開く本物のターミナルです。
1. {{ui:menu.addTerminalPane}}({{kbd:⌘T}})を選ぶか、{{ui:workspace.addPane}} → {{ui:workspace.newTerminal}}を選びます。
2. コマンドを直接入力します。

シェルが終了したら{{ui:terminal.restart}}をクリックします。以前のコマンド履歴は、ペインのヘッダーの…メニューの{{ui:pane.menu.terminalHistory}}で確認できます。ペインのヘッダーを右クリックしたメニューの{{ui:terminal.history.title}}も同じです。アプリを終了すると、ターミナルは再び開かれません。

![[terminal-pane]]

### 通知とベル {#terminal-signals}
ターミナルペインのプログラムや、アプリが読み取らない CLI が通知やベルを送ると、そのペインに表示します。通知は OSC 9(`printf '\e]9;ビルド完了\a'`)、OSC 777(`notify;タイトル;本文`)、OSC 99(kitty、タイトルと本文のみ)を受け取ります。進捗を知らせる `9;4;…` は通知ではありません。本文は制御文字を除いて 200 文字まで表示し、1 つのペインで 1 秒に 1 つだけ受け取ります。
- 別のペインを見ているときやアプリが背面にあるときは、サイドバーのそのペインの行とタブに点が付き、ペインの枠が強調されます。通知なら OS の通知も届きます。ベルは表示だけです。
- エージェントペインが承認や質問の回答を待っているときや、worktree の setup が失敗したときも同じ表示が付きます。{{ui:phone.dashboard.title}}には待っているペインの数が表示され、クリックするとそのペインへ移動します。
- {{kbd:⇧⌘U}}(Windows: {{kbd:Ctrl+Shift+U}})を押すと、最後に知らせたペインへ移動します。もう一度押すと次のペインへ移動します。メニューバーの{{ui:menu.workspace}}メニューの{{ui:attention.next}}も同じです。
- ペインを見ると表示は消えます。いま見ているペインの通知は、表示も OS の通知もしません。
- 受け取らないときは、[設定](settings.md#companion)の{{ui:terminalNotifications.toggle}}をオフにします。

### 開いているポートと PR {#pane-ports}
ペインのシェル、エージェント、run アクション、その下で動くプログラムが開いた TCP ポートを 10 秒ごとに読み、サイドバーのペインの行と worktree バーに表示します。アプリのウィンドウが見えている間、いまのワークスペースのペインだけを読みます。worktree バーのポートをクリックすると、ブラウザで `localhost` を開きます。

worktree ペインには、そのブランチの PR の番号と状態(オープン・ドラフト・マージ済み・クローズ)、チェック結果(成功・失敗・実行中)も表示します。PR は 2 分ごとに読み直し、クリックすると PR のページを開きます。サイドバーが狭いと、ポートと PR はアイコンだけになります。

### エージェントのターミナル {#agent-terminal}
ClaudeやCodexがユーザーに見せる必要のあるコマンド(開発サーバー、サインインなど)を実行すると、エージェントペインの右側に専用のターミナルペインが作られます。実行中のコマンドに直接入力できます。ペインを閉じてもコマンドはアプリを終了するまで動き続け、ペインのヘッダーにある{{ui:agentTerminal.terminalPane.open}}ボタンで再び開けます。

## ファイルペイン {#files}
ワークスペースのファイルを閲覧する、読み取り専用のペインです。ファイルを編集することはありません。
1. {{ui:menu.showFiles}}({{kbd:⇧⌘E}})を選ぶか、ワークスペースのヘッダーにあるフォルダのボタンをクリックします。
2. 左の一覧からファイルを選びます。{{ui:files.tree.filter}}で名前を検索し、矢印キーと{{kbd:Return}}で移動します。
3. 右側で内容を確認します。

| ファイル | 表示のされ方 |
|---|---|
| ソース・テキスト | 行番号とシンタックスハイライト付き。大きなファイルは最初の1 MBだけが表示されます。 |
| Markdown | {{ui:files.markdown.rendered}}と{{ui:files.markdown.source}}の表示を切り替えます。128 KBを超えるファイルはソースで表示されます。 |
| HTML | ページとして描いた{{ui:files.markdown.rendered}}と{{ui:files.markdown.source}}の表示を切り替えます。 |
| 画像・PDF | {{ui:files.image.fit}}、{{ui:files.image.actualSize}}、{{ui:files.image.zoomIn}}、{{ui:files.image.zoomOut}}。PDFは最初のページだけが表示されます。50 MBを超える画像はプレビューせず、1億画素を超える画像は全体表示だけになります。 |
| その他 | {{ui:files.preview.unsupported}}。{{ui:menu.showInFinder}}で開きます。 |

ワークスペース外のファイルは表示されません。ファイルが変更された場合は{{ui:files.tree.refresh}}をクリックします。

### エディタで開く {#open-in-editor}
ファイルを直すときは、いつものエディタで開きます。行がわかっている場所では、その行に直接移動します。
- ファイルペイン: プレビューのヘッダーの{{ui:editor.open}}ボタン、一覧でファイルやフォルダを右クリックしたメニュー({{ui:editor.openFolder}})。
- 会話とMightyフロー: ファイル名を{{kbd:⌘}}-クリック(Windows: {{kbd:Ctrl}}-クリック)すると、プレビューの代わりにエディタでその行を開きます。プレビューのヘッダーと結果のファイル一覧の各行にあるボタンも同じです。
- 変更の表示: [リクエストの変更をレビュー](agent-pane.md#request-changes)とworktreeペインの変更表示で行を右クリックするとその行を、ボタンは選んだファイルを開きます。
- worktreeペインのバーのメニューと[レビュー待ち](layout.md#review)ではworktreeのフォルダを開きます。

使うエディタは[設定](settings.md#agents)の{{ui:settings.editor.label}}で選びます。自動では、VS Code、Cursor、Zed、JetBrains IDE(IntelliJ IDEA、WebStorm、PyCharmなど)、Sublime Textの順で最初に見つかったものを使います。ログインシェルのPATHにあるコマンド(`code`、`cursor`、`zed`、`idea`、`subl`)を先に探し、Macではアプリケーションフォルダのアプリに入っているコマンドを、Windowsでは通常のインストールフォルダにある実行ファイルを探します。{{ui:settings.editor.system}}は行番号なしでファイルの既定アプリで開き、コードを実行するファイルは開きません。ワークスペースやworktreeの外のパスは開きません。

## Webリンク {#web-links}
返答の中のWebリンクや、エージェントが開くWebページは、既定のブラウザで開きます。

## ライブプレビュー {#live-preview}
エージェントペインのヘッダーにある地球のアイコン({{ui:preview.button.name}})を押すと、このワークスペースで待ち受けている開発サーバーを探して表示します。{{ui:preview.menu.main}}と各 worktree ペインのポートブロック、そのフォルダで動いている実行アクションが見つけたアドレスを一度ずつ問い合わせ、Webサーバーだけを選びます。1つ選ぶと、そのサーバーが属するペインのプレビューで開きます。ペインが複数あるときは、すべて開くでペインごとに1つずつ開きます。

1. プレビューは、このコンピューターにインストールされた Chrome、Edge、Chromium、Brave のいずれかを別に起動したウィンドウです。毎回新しいプロファイルを使い、普段使っているブラウザのログインやCookieは使いません。どれもなければ既定のブラウザで開き、要素の選択は使えません。
2. プレビューが開いているペインには、入力欄の上に帯が表示されます。{{ui:preview.strip.pick}}を押してプレビューウィンドウで要素をクリックすると、その要素のタグ、一意のセレクター、主なスタイル、テキストの一部、React・Vue・Svelte・Angular のコンポーネントの手がかりが入力欄に添付され、アプリがそのペインに戻ります。「このボタンの間隔を詰めて」のように書き足して送ってください。
3. {{ui:preview.strip.shotPage}}は見えている画面を、要素を選んだ後はその要素の範囲だけを撮って添付します。コンソールエラーと失敗したリクエストのボタンは、ページを最後に読み込んでからのエラーを一度に添付します(ないときは押せません)。
4. {{ui:preview.strip.close}}を押すか、プレビューウィンドウを閉じると終わります。最後のプレビューが閉じると、そのブラウザも終了し、プロファイルは削除されます。

> [!note]
> プレビューが開くのは、`localhost`・`127.0.0.1`・`::1` で、かつそのペインのポートブロックか実行アクションのアドレスの範囲内のアドレスだけです。ページがその外へ移動しようとすると止め、帯でお知らせします。ペインのプログラムがポートブロックの外で待ち受けているポートはメニューに表示されるだけで、開きません。`MIGHTY_PORT` でサーバーを起動すると開けます。プレビューのページはアプリとは別のプログラムで開くため、アプリに届きません。SSH とリモートのワークスペースにはまだプレビューがありません。
