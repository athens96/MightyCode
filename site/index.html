Mighty Code

macOS · Windows · Android

Claude Code · Codex · Antigravity · pi · opencode · Hermes를 한 창에서 나란히 쓰는 데스크톱 앱입니다.
프로젝트 폴더(워크스페이스)마다 여러 실행 창을 열고, 창마다 에이전트 CLI를 직접 실행해 대화와 설정을 따로 유지합니다. 요청·하위 에이전트·백그라운드 작업을 블록 흐름으로 보여 주는 마이티 보기, 정해진 순서로 일을 진행하는 스타일(오로보로스·클러드 플랜), 일을 자기 git worktree를 가진 자식 창에 나눠 맡기는 마이티 오케스트레이션, 다른 컴퓨터의 워크스페이스를 여는 원격 연결(Tailscale), 휴대폰에서 상태를 보고 답하는 휴대폰 원격이 있습니다.

주요 기능

각 기능의 자세한 사용법은 문서(도움말)에 있습니다.

에이전트 창과 마이티 보기 03

실행 중에도 다음 요청을 대기열(창당 16개)에 넣을 수 있습니다. 모든 에이전트 창은 요청 → 그 사이에 일어난 일 → 최종 결과를 블록 흐름으로 보여 주고, 흐름·기록·파이프라인 보기로 전환합니다.

마이티 오케스트레이션 06

에이전트 창이 일하는 동안 다른 일을 옆의 자식 창에 맡깁니다(⌘Enter 또는 delegate 도구). 자식은 저마다 자기 git worktree(mighty/<자식 id>)에서 일하고, 끝나면 부모 브랜치에 병합하거나 버립니다. 자식은 Claude, Codex, Antigravity로 실행할 수 있습니다.

스타일과 계획 카드 04

Claude 창에서 입력창 위 메뉴로 오로보로스(Ouroboros)와 클러드 플랜 스타일을 고릅니다. 클러드 플랜은 새 요청마다 계획 모드로 시작하며, 계획 카드와 데스크톱 펫에서 승인·수정 요청·취소를 고릅니다.

승인·질문·로그인 복구 05

권한 밖의 일은 승인 카드로, 질문은 선택 요청 카드로 묻습니다. Antigravity는 거절한 작업을 턴 끝에 모아 묻고, 허용하면 같은 대화를 이어갑니다. CLI 로그인이 만료되면 복구 카드에서 다시 로그인하고 실패한 요청을 다시 보냅니다.

터미널·파일·브라우저 창 07

터미널 창(⌘T)은 워크스페이스 폴더에서 열리는 실제 터미널입니다(Mac은 Ghostty, Windows는 PowerShell). 파일 창(⇧⌘E)은 소스·Markdown·이미지·PDF를 미리 보고 변경점을 비교합니다.

원격 연결(Tailscale)과 휴대폰 원격 09 · 10

Mac이나 Windows 두 대를 Tailscale로 이어 다른 컴퓨터의 워크스페이스를 열거나, QR 코드로 휴대폰을 연결해 종단 간 암호화(릴레이 또는 Tailscale 직접 연결)로 상태를 보고 답합니다.
