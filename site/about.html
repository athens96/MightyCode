개요

Mighty Code는 프로젝트 폴더(워크스페이스)마다 여러 실행 창을 열고, 창마다 에이전트 CLI(Claude Code, Codex, Antigravity, pi, opencode, Hermes)를 직접 실행해 대화와 설정을 따로 유지하는 데스크톱 앱입니다. 화면은 한국어·영어·중국어·일본어로 볼 수 있습니다.

구조 (Rust + Tauri 2)

macOS 앱과 Windows 앱은 하나의 Rust + Tauri 2 워크스페이스(native/tauri)로 만들어집니다. 공통 로직(mighty-core, mighty-run, mighty-graph, mighty-delegation, mighty-remote, mighty-tools)은 OS 코드 없이 공유하고, 플랫폼마다 다른 부분은 포트(mighty-platform)에 각 운영체제 구현을 끼워 넣습니다.

macOS

Rust + Tauri 2 + objc2(AppKit). 터미널은 네이티브 Ghostty(libghostty C API, Metal) 뷰를 올리고, 브라우저는 CEF와 WKWebView 중 설정으로 고릅니다. macOS 14 이상, Apple Silicon.

Windows (베타)

Rust + Tauri 2 + WebView2. 터미널은 Rust ConPTY + xterm.js를 쓰고, 프로세스 관리는 Job Object, 비밀값 저장은 DPAPI를 씁니다. Windows 10(2004) 이상 또는 Windows 11, x64·ARM64.

휴대폰 (Android)

React Native(Expo) Android 앱. 릴레이 서버를 거쳐 종단 간 암호화(X25519 → HKDF → ChaCha20-Poly1305)로 연결하며, 같은 Tailscale 네트워크면 컴퓨터에 직접 연결합니다.

동작 원칙과 지원 범위

  • 앱은 sudo를 쓰지 않고 시스템 비밀번호를 받지 않습니다.
  • 릴레이는 암호문만 전달하고 아무 비밀도 모르며, 파일로 된 스타일은 내용을 확인해 허용한 뒤에만 씁니다.
  • 자동 업데이트는 매니페스트의 Ed25519 서명을 확인한 뒤에만 설치합니다.
  • Claude를 뺀 에이전트 창(Codex, Antigravity, pi, opencode, Hermes)에는 베타 표시가 붙습니다.
  • pi, opencode, Hermes 창은 아직 마이티 오케스트레이션과 원격 워크스페이스에서 쓸 수 없습니다.

저장소와 빌드

소스 코드, 릴레이(Cloudflare Workers / Oracle Cloud 배포 스크립트), 도움말 원문, CI 워크플로는 GitHub 저장소에 있습니다.
